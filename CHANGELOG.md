# Changelog

## 1.0.0 (2026-06-01)

- Initial release
- 9 supported AI coding agents (OpenCode, Claude Code, Cursor, Cline, GitHub Copilot, Codex CLI, Gemini CLI, Goose, PI Agent)
- Multi-agent unified session listing
- Per-step token breakdown (input, output, reasoning, cache)
- Efficiency analysis with Grade A-D
- Anomaly detection with Z-score
- Session comparison (side-by-side)
- Outlier detection
- ASCII trend charts
- Monthly reports (per-provider, per-project)
- Budget tracking
- JSON/CSV export
- Text search by title
- Shell integration (zsh shortcuts)
- Zero dependencies, zero telemetry, fully offline
